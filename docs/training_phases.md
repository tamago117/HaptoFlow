# Two-phase training

At inference, each segment is generated from the model's own previous output.
Phase 1 trains with the recorded previous segment; phase 2 fine-tunes with
previous segments generated by the model itself.

| phase | config | start |
| --- | --- | --- |
| 1 | `configs/train/flow_matching.yaml` | scratch |
| 2 | `configs/train/flow_matching_phase2.yaml` | `--init-from` a phase-1 checkpoint |

```bash
uv run scripts/train.py --model flow_matching -r haptoflow_phase1
uv run scripts/train.py --model flow_matching --config configs/train/flow_matching_phase2.yaml \
    --init-from runs/haptoflow_phase1/epoch_0050 -r haptoflow_phase2
```

Checkpoints are written to `runs/<run>/epoch_XXXX/`; an interrupted run resumes
with `--resume <checkpoint dir>`.

## Phase 2

Each sample is a chain of `train.self_forcing.num_unroll` consecutive segments.
With probability `self_forcing.prob`, the previous segments along the chain are
generated by the model (`sampling.steps`, `sampling.guidance_scale`), and
`self_forcing.loss_pairs` pairs per chain are used in the loss.
`data_augmentation.zero_prev.prob` starts a chain from silence, as at the start
of inference.

## Validation

Besides the loss and waveform metrics (SNR, RMSE, GFC, spectral RMSE), validation
generates chains of `eval.self_forcing.num_unroll` segments and logs GFC and
spectral RMSE along them.
